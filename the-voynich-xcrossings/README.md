# The Voynich XCrossings

共通部第一〜四部・第4稿のWeb試読版。ラーナ・ミーシャの第4稿を独立した試読ページで公開しています。共通部の読了後に選べます。

公開先: https://games.syncworld.net/the-voynich-xcrossings/

## 操作

- 本文クリック／タップ、Space、→、PageDown: 次のページ
- ←、PageUp、Shift+Space: 前のページ
- 目次で章へ移動。未読の章名は伏せます。
- 文字サイズ、ページ長、明暗を変更できます。
- 読書位置をブラウザーに保存。旧稿の位置は同じ章の近い箇所へ移します。旧個別ルートの位置は共通部の試読末尾へ移します。
- 最初から読む場合は `?draft=4#at=0&rev=draft4-v1`。

## ソースと検証

`manuscript.md` が公開原稿、`src/` が表示と操作です。

```sh
python3 build.py
node --test tests/reader.test.cjs
```

`index.html` は外部依存のない単独HTMLです。`reading-migrations.json` は第3稿の各版から第4稿への段落対応を含みます。`rana/` と `misha/` は共通第四部から分岐する独立したルートで、それぞれ読書位置を保存します。共通部の読書位置は維持します。

## 全ルート

画面上部の「ルート」から共通部、ラーナ、ミーシャ、澪、律の後日譚へいつでも移動できます。各ページで読書位置を別に保存します。推奨順はこの記載順です。澪までが独立した分岐で、律の後日譚は澪エンド後の続きです。
