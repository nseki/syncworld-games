# The Voynich XCrossings

第一部〜第四部＋ラーナルート・第3稿のWeb試読版。背景・立ち絵・音声・分岐を付けず、ページ送りで文章のテンポを確認します。

公開先: https://games.syncworld.net/the-voynich-xcrossings/

## 操作

- 本文クリック／タップ、Space、→、PageDown: 次のページ
- ←、PageUp、Shift+Space: 前のページ
- 目次: 章の移動。未読の章名は隠します
- 文字・表示: 文字サイズ、ページ長、明暗の変更
- 読書位置と表示設定はブラウザー内に保存。`#at=段落番号` で位置を共有できます

`index.html` 単体をダウンロードしても読めます。

## ソース

`manuscript.md` が原稿、`src/` が表示と操作、`build.py` が単独HTMLの生成、`tests/` が原文保持・ページ分割・再開位置などのチェックです。

```sh
python3 build.py
node --test tests/reader.test.cjs
```

現在は第三部・第四部を改修した共通部と、ラーナルートの第3稿を公開しています。
GUIブラウザーでの表示確認は未実施です。

第三部・第四部は、台詞や描写の後に続く意味の説明を圧縮しています。`reading-migrations.json` は、削除前の段落位置から現行本文への対応表です。保存位置と旧 `#at=` リンクは同じ章の対応箇所へ引き継ぎ、新しい保存位置とリンクには版を記録します。

## ミーシャルート

`misha/` は共通第四部から分岐する独立した試読ページです。ラーナルートの読了ページから移動できます。読書位置は共通部・ラーナルートと別に保存します。表は独立したページで表示し、横にスクロールして読めます。
