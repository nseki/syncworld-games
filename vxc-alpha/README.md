# The Voynich XCrossings — サウンドノベル暫定α

ZIPを展開し、`index.html` をブラウザーで開いてください。HTML単体で本文、背景、水音を再生できます。音声は初期状態でOFFです。

- 「次へ」「戻る」または左右の矢印キーでページを移動できます。最終ページの「最初へ」で再読できます。
- 「本文を隠す」で下部の本文だけを隠し、背景を見られます。
- 「音声 OFF」を押すと水音が始まります。ページごとの音量へフェードし、無音の場面を挟みます。
- 本文が画面に収まらないときは、本文欄の中をスクロールしてください。

## 制作素材

- 原稿は [nseki/stories の common.md](https://github.com/nseki/stories/blob/main/the-voynich-xcrossings/manuscripts/common.md) の序章。参照時のファイルの Git blob は `ab934c0f53c16bb05cfbe53aa56d0fcb2eb9c2f0`。同梱の `prologue.md` は該当箇所の抜粋です。本文は原文の段落で区切り、23ページに配分しました。
- 指定のv0.1と実写風画像は受領待ちです。この暫定版は新規のHTMLで、地下水路と室内の5画面に仮の色面を使っています。最終画面は、原稿が指定している図版を表示します。

## 音源・図版クレジット

- 水音「Rushing Stream River Water」／ RyanKingArt。録音ファイル `726522__ryankingart__rushing-stream-river-water.m4a` をHTML内に収録し、ブラウザーでループと音量フェードを適用。 [Freesound #726522](https://freesound.org/people/RyanKingArt/sounds/726522/) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- 図版 Beinecke MS 408, f. 38r ／ Yale University Library。 [資料ページ](https://collections.library.yale.edu/catalog/2002046?child_oid=1006148)
