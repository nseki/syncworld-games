# The Voynich XCrossings — 全編試読版

[試読版を開く](https://games.syncworld.net/vxc-alpha/)

「次へ」「戻る」または左右の矢印キーで進みます。冒頭と手稿の場面では、画像をタップするか「本文を読む」を押すと本文が表示されます。「目次・ルート」から各編や章に移動できます。律の後日譚は澪編の末尾からも開けます。

読んでいる編と各編のページ位置は、同じブラウザーに保存されます。「音声 OFF」を押すと序章の水音が有効になります。

## 原稿と素材

- [nseki/stories の原稿](https://github.com/nseki/stories/tree/main/the-voynich-xcrossings/manuscripts) 5本を `manuscripts/` に収録。ページ割りは `story.js` に収録。
